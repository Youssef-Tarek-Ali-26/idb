# Change: Add N-Space Theory Foundation

## Why
iDB's core thesis is a unified N-dimensional space, but the repo lacks a formal contract for decomposing that space and evaluating fused similarity across structured, semantic, and topology signals.

## What Changes
- Add a formal N-space model contract to unified spatial storage specs.
- Add a theory document that defines decomposition, kernels, invariants, and v0 assumptions.
- Add `idb-core` N-space types and similarity kernel utilities as executable reference primitives.

## Impact
- Affected specs: `unified-spatial-storage`
- Affected code: `idb-core`
- Affected docs: `docs/research`
